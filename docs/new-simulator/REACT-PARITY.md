# React editor parity inventory

Updated 2026-11-17. Full parity targets the original bundled Java/GWT Falstad app;
The intermediate JavaScript editor was retired on 2026-11-17. Reference-column
names such as `editor.js` and `scope-view.js` below identify historical behavior
available in Git history, not files to retain or import. Menu metadata now lives
in `wires/src/editor/menu`; regression helpers live in `tools/engine-harness`.
React is the active editor. Full Falstad compatibility and unchecked browser
behavior remain open; removing the prototype does not certify parity.

| Feature | Reference | React implementation and remaining checks |
| --- | --- | --- |
| New, Open, Save and autosave | `editor.js` file handlers, `changed()`, startup | File commands share the editing session, reset selection and tools on replacement, and show autosave status. Verify reload, invalid and overlapping file loads, and save/open round trips in React. |
| Examples | `editor.js` startup, schema-v1 files in `examples/` | File → Open example lists all 11 schema-v1 editor examples. The standalone preview loads its selected fixture with autosave disabled. The full Falstad example library depends on legacy text import and model support. |
| Edit commands and keyboard | `editor.js` command handlers and `keydown` | A shared command path handles the Edit menu and shortcuts. Copy with no selection targets the item under the pointer. Paste and Duplicate preview the copied graph, support rotation and flips, and commit through history. Check selection cleanup, cancellation, focus and undo/redo after wire normalization. |
| Camera, grid and selection | `editor.js` `fit()`, wheel and marquee handlers, `editor.css` | Lines are the default grid. View offers zoom and fit. Resize keeps the viewport centered. Directional marquee and Shift selection use the shared geometry. Clicking a member of a multi-selection collapses it on release unless dragged. Check zoom and pan with open scope panes and compare pointer feedback. |
| Placement, drag and wire routing | `editor.js` placement, pointer and transform handlers | Repeat placement supports R/Shift+R and X/Y, including the + on top op-amp preset. Sheet labels use upright text for each pose. G and pointer drag use the shared drag graph. M and reorientation detach, and loose ends can preview reconnects. A new wire starts on a pin, junction, or wire. Check label orientation, Shift and pointer capture, drop contacts, Escape, and exact undo states. |
| Add menu and supported components | `legacy-component-menu.js`, `component-menu.js`, `editor.js` `menuPanel()` and `symbol()` | React uses the reference hierarchy, labels and availability map. All 84 supported models use authored TSX views in the sheet and placement preview. The 19 most recent additions ran in the compiled worker and accepted live edits. See [PLAN.md](PLAN.md) for the remaining menu entries. Check nested arrow navigation, Escape, focus restoration, symbol orientation, and appearance on representative circuits. |
| Property editing and readings | `editor.js` `inspector()`, `editComponent()` | The full-width React sheet opens a shadcn dialog on double-click or E. The component dialog includes fields, live readings and applicable meter and recorder actions. Ammeter, voltmeter, ohmmeter, wattmeter and test point show live sheet readings above by default; the first three share the resized ammeter design, and the wattmeter retains four terminals. Check rotated/mirrored labels, old circuit pin alignment and all meter modes. React omits component designators in the sheet, dialogs and saved documents. Check focus restoration, per-kind field labels, output presentation and audio behavior. |
| Variable voltage and potentiometer wiper | `editor.js` `inspector()`, `editComponent()`, `voltage-slider.js`, `PotElm.java` | Placement, View → Sliders and either component's dialog open one draggable shadcn card. The list is reorderable and its order is saved locally per circuit. Slider labels are saved in circuit JSON. Adjustments preview live and commit on release. The wiper arrow follows the preview while the wired terminal stays fixed. Headless checks covered the rendered range and potentiometer label compatibility. Browser checks still include panel focus, pointer drag, keyboard reorder and scope readings at both wiper endpoints. |
| Sampling, scaling and cursor | `editor.js` `sync()`, Run/Step/Reset, `scope-view.js`, native Falstad scopes | Per-step signed voltage/current batches retain 10-step/16-ms cadence. Each pane owns time/div; each trace owns scale/position/coupling. Selected trace controls the coloured axis. Hover reads live at fixed pointer position; click-and-hold tracks a sample. Every pane/value uses the exact shared timestamp, hiding out-of-window samples. Frequency/period and trigger/FFT remain open. |
| Scope UI and layout | Native Falstad scope workflow plus user-directed React interaction | New probes create scopes; combine/separate, nested horizontal/vertical dock splits, resizable panel/dividers, grip reordering/undock/redock. Floating panels snap with margins to panels/edges; sheet scopes snap to grid, scale with symbols and pass navigation through. Dock height caps at 50%; closing it leaves undocked scopes visible. Names/gears stack bottom-left; cursor value and scales sit top-right. No side legend or removed toolbar controls. User reported improved responsiveness after caching/camera isolation; interactive checks remain pending. |
| Scope persistence and properties | Circuit JSON and document history | Optional version-1 `layout.scopes` saves grouping, selected axes, time scales, nested dock tree/ratios/order, modes, geometry/reference zoom and panel height/open state. Gestures commit on release and support Undo; old files use defaults. Trace settings remain on probes. Properties groups appearance/scale/position with collapsed raw mean/RMS/peak-to-peak/min/max. Browser save/open/Undo verification remains pending; do not run it unless requested. |
| Cutover | Both editor entry points and the engine worker | The intermediate editor has been removed. React and its standalone preview remain; resolve behavior gaps against retained fixtures and the original Falstad app. |
